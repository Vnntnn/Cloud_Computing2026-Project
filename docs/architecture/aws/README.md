## How the as-built differs from the target

- **CloudFront → ALB + WAF.** CloudFront is denied in the Learner Lab (probed 2026-10-25). The ALB terminates TLS and the WAF
  (Common, KnownBadInputs, IP reputation, a per-IP rate limit; block mode; the Stripe webhook path is allowed) sits in front of it.
  The WAF is not in the target.
- **NLB → ALB.** The target's NLB behind CloudFront is replaced by the ALB (idle timeout 3600 s for the live-seats WebSocket).
- **Shield:** only the automatic Shield Standard (Advanced is denied, and costs $3,000/month).
- **Not drawn in the target:** the empty 1b subnets (ALB, EKS and the RDS subnet group each need two AZs), the `sts`, `ec2` and
  `secretsmanager` interface endpoints (a node with no route out needs them to join, and RDS Proxy needs the last one), the
  15 CloudWatch alarms, the SNS topic and the dashboard `eventide`.
- **v2 app flows instead of the target's v1 ones:** session cookie + `auth-guard` (not JWKS), uploads through the services and
  `/files/*` rewritten by the ingress to S3 (not presigned URLs), a Bun web server with Open Graph tags (not an nginx SPA).
- **Not production-grade, by lab constraint:** single AZ (as drawn), no RDS backups (the database is rebuilt every session),
  pods use the 4-hour session credentials (no IRSA), the EKS API endpoint is public, WAF and ALB logging are off, and the platform
  runs only during sessions (`make up` / `make down`, the $50 cap).

Marked "pending" (orange dashed) = not live yet: the CI deploy job (needs `make ci-creds`).

The arrows were derived from the code and the Terraform, not from memory: which workspaces import `@app/db`, use Redis, call
`authGuard`, call `enqueueMail`, use `@app/storage`, which node group each Deployment is pinned to (`values.aws.yaml`), and the
route tables, security groups and endpoints in `infra/terraform`.

## Regenerate

```sh
python3 docs/architecture/aws/build_as_built.py            # writes the .drawio
docker context use default                                  # if the client points at Docker Desktop
cd docs/architecture/aws
docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD:/data" rlespinasse/drawio-export \
  -f png --scale 1 --border 20 --remove-page-suffix --output render /data
mv render/eventide-aws-as-built.png . && rmdir render
docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD:/data" rlespinasse/drawio-export \
  -f svg --scale 1 --border 20 --remove-page-suffix --embed-svg-fonts false --output render /data
mv render/eventide-aws-as-built.svg . && rmdir render
```

(Export one format per run. Running as your own user keeps the output files removable.)
